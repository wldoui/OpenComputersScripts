REAL API USED BY THIS BUILD

Source basis: supplied HBM OpenComputers integration specification and the user's
HBM Space 0.9.2 source inspection.

ntm_stardar:
  getPlanetStats(string)
  getCurrentPlanet()
  getSatellites(string)

ntm_rocket_pad:
  getEnergyInfo()
  getFuel()
  getSolidFuel()
  canLaunch()
  getRocketStats()
  launch()
  getDestination()

THIS BUILD DOES NOT CALL launch().

ntm_radar (documented, not automatically used for Space tracking):
  getEntityAtIndex(number)
  getAmount()
  getPos()
  getIndexType(number)
  isIndexPlayer(number)
  getRange(number)
  getSettings()
  setSettings(...)
  isJammed()
  getEnergyInfo()

The ntm_stardar API does not provide satellite XYZ or velocity in the documented
callbacks. The ntm_rocket_pad API provides rocket stats/destination but not
world-space telemetry. The renderer therefore does not invent coordinates.
